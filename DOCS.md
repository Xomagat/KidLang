## Быстрый старт

### Сборка

Нужны CMake ≥ 3.31 и компилятор с поддержкой C++20.

```bash
cmake -B build
cmake --build build
```

На Linux бинарник собирается статически, на Windows статически подключаются `libgcc` и `libstdc++`.

### Запуск

```bash
kid программа.kl     # выполнить программу
kid -v               # показать версию
```

Файл обязан иметь расширение `.kl`, кодировка — UTF-8 (BOM допускается). Цвета в ошибках отключаются переменной окружения `NO_COLOR`.

### Первая программа

```
текст имя = получи("Как тебя зовут? ")
покажи("Привет, " + имя + "!")
```

## Основы

### Комментарии

Комментарий начинается с `;` и идёт до конца строки.

```
; это комментарий
покажи(1) ; и это тоже
```

### Отступы

Блоки задаются **отступами** (как в Python). Двоеточий и фигурных скобок для блоков нет. Табуляция считается за 4 пробела. Все строки одного блока должны иметь одинаковый отступ.

Отступы не учитываются внутри скобок `()`, `[]`, `{}`, поэтому списки и словари можно переносить на несколько строк:

```
список число числа = [
    1, 2, 3,
    4, 5, 6
]
```

### Имена

Имена переменных, рецептов и классов могут содержать латинские и русские буквы (включая `ё`), цифры и `_`, но не могут начинаться с цифры. Ключевые слова использовать как имена нельзя (см. [список](#зарезервированные-слова)).

### Числа и текст

- Числа: `42`, `3.14`. Отрицательные получаются унарным минусом: `-5`.
- Текст — в двойных или одинарных кавычках: `"привет"`, `'привет'`.
- Экранирование: `\n`, `\r`, `\t`, `\\`, `\"`, `\'`.

## Типы данных

| Тип | Описание | Значение по умолчанию |
|---|---|---|
| `число` | число с плавающей точкой | `0` |
| `текст` | строка (UTF-8) | пустая строка |
| `условие` | логическое: `верно` / `неверно` | `неверно` |
| `список` | упорядоченный набор однотипных значений | пустой список |
| `словарь` | пары ключ–значение | пустой словарь |
| `ничего` | отсутствие значения | — |
| *имя класса* | объект пользовательского класса | нужно задать значение явно |

Типы **строгие**: в переменную типа `число` нельзя положить текст, и наоборот. Для перевода используйте [`преврати`](#преобразование-типов).

Как значения приводятся к условию (в `если`, `пока`, `не`, `и`, `или`):

| Значение | Ложь | Истина |
|---|---|---|
| число | `0` | всё остальное |
| текст | `""` | непустой |
| список, словарь | пустой | непустой |
| `ничего` | всегда ложь | — |
| объект | — | всегда истина |

Числа выводятся «красиво»: целые без дробной части (`5`, а не `5.0`), нечисловые значения — как `не число`, `бесконечность`, `-бесконечность`.

## Переменные

### Объявление

```
число x = 5
текст имя = "Маша"
условие готов = верно
число y            ; = 0
текст пусто        ; = ""
```

### Присваивание

Для уже существующей переменной тип не пишется:

```
x = 10
x = "текст"        ; ОШИБКА: в x должно лежать число
```

Если переменной нет, будет ошибка: «Я не знаю переменную … Сначала создай её».

### Составное присваивание

`+=` `-=` `*=` `/=` `%=` `**=` `//=`

```
x += 1
x **= 2
```

### Области видимости

Каждый блок (`если`, `пока`, `повтори`, `для`, тело рецепта) создаёт свою область видимости. Переменная, объявленная внутри блока, снаружи недоступна. Присваивание переменной без типа ищет её во внешних областях.

### Преобразование типов

Выражение `преврати <выражение> в <тип>`:

```
число n = преврати "42" в число
текст s = преврати 3.5 в текст
условие b = преврати "верно" в условие
```

| В тип | Из текста | Из остальных |
|---|---|---|
| `число` | разбирается как число, иначе ошибка | `as_number` значения |
| `текст` | — | строковое представление |
| `условие` | только `"верно"` / `"неверно"` | по правилам приведения к условию |

## Операторы

### Арифметика

| Оператор | Действие |
|---|---|
| `+` `-` `*` `/` | сложение, вычитание, умножение, деление |
| `//` | целочисленное деление (с округлением вниз) |
| `%` | остаток |
| `**` | степень |
| `x!` | факториал (целое от 0 до 170) |
| `-x`, `+x` | унарные знаки |

Деление на ноль (`/`, `//`, `%`) — ошибка.

### Текст

- `"а" + "б"` — склеить. Справа может быть и число: `"x = " + 5` → `x = 5`.
- `"ab" * 3` — повторить (`ababab`). Отрицательное число — ошибка.
- Число слева, текст справа (`5 + "а"`) — ошибка: нельзя смешивать.

### Сравнение

`==` `!=` `<` `>` `<=` `>=`

- Тексты можно сравнивать только через `==` и `!=`.
- `== ничего` и `!= ничего` работают с любым значением.

### Логика

`и`, `или`, `не`. Вычисление **ленивое**: если результат ясен по левой части, правая не вычисляется.

```
если x > 0 и x < 10
    покажи("от 1 до 9")
```

### Приоритет (от низкого к высокому)

1. `или`
2. `и`
3. `не`
4. `==` `!=`
5. `<` `>` `<=` `>=`
6. `+` `-`
7. `*` `/` `//` `%`
8. унарные `+` `-`
9. `**`
10. `!` (факториал)
11. `.метод()`, `[индекс]`, вызовы

## Ввод и вывод

```
покажи(выражение)       ; вывести значение и перевод строки
текст s = получи()      ; прочитать строку
текст s = получи("Подсказка: ")
```

`покажи` требует скобки. `получи` всегда возвращает **текст**; для числа используйте `преврати ... в число`.

```
число возраст = преврати получи("Сколько лет? ") в число
покажи("Через год тебе будет " + (возраст + 1))
```

## Условия

```
если x > 10
    покажи("много")
может x > 5
    покажи("средне")
может x > 0
    покажи("мало")
иначе
    покажи("ноль или меньше")
```

- `может` — это «иначе если», их может быть сколько угодно.
- `иначе` — необязательная последняя ветка.
- После условия не нужно ставить двоеточие, а следующие строки обязательно сдвигаются вправо.

## Циклы

### `повтори`

```
повтори 5 раз
    покажи("привет")
```

Допустимы слова `раз` и `раза` (`повтори 2 раза`).

### `пока`

```
число i = 0
пока i < 3
    покажи(i)
    i += 1
```

### `для` — по числам

Конец **включается** в диапазон. Шаг по умолчанию — `1`; задаётся числовым литералом после `добавляя` (можно отрицательный).

```
для число i от 1 до 5
    покажи(i)

для число i от 0 до 10 добавляя 2
    покажи(i)

для число i от 10 до 1 добавляя -1
    покажи(i)
```

Нулевой шаг — ошибка. Цикл «от … до» работает только с типом `число`. Предел `до` пересчитывается на каждой итерации.

### `для` — по списку

```
список текст имена = ["Аня", "Боря", "Вера"]
для текст имя из имена
    покажи(имя)
```

Тип переменной должен совпадать с типом элементов списка. Цикл идёт по **копии** (снимку) списка, поэтому список можно менять прямо внутри цикла.

### `стоп` и `продолжи`

```
для число i от 1 до 10
    если i == 3
        продолжи       ; пропустить итерацию
    если i == 6
        стоп           ; выйти из цикла
    покажи(i)
```

Вне цикла эти слова приводят к ошибке.

## Рецепты (функции)

### Объявление и вызов

```
рецепт привет(текст имя)
    покажи("Привет, " + имя)

рецепт сумма(число a, число b) вернёт число
    верни a + b

привет("Маша")
число s = сумма(2, 3)
```

- Тип результата указывается после скобок: `вернёт <тип>` (допустимо и `вернет`).
- Если типа нет (или `вернёт ничего`), рецепт ничего не возвращает.
- Если рецепт обещал вернуть значение, но не вернул — ошибка («Забыл написать «верни»?»). Тип возвращаемого значения тоже проверяется.
- `верни` без выражения на той же строке возвращает `ничего`.

### Значения по умолчанию

```
рецепт приветствие(текст имя, текст слово = "Привет") вернёт текст
    верни слово + ", " + имя

покажи(приветствие("Маша"))
покажи(приветствие("Маша", "Здравствуй"))
```

Параметры со значениями должны идти **в конце** списка.

### Правила

- Количество и типы аргументов проверяются строго (`число` не превращается в `текст` сам).
- Рецепт видит только **глобальные** переменные и свои параметры, но не локальные переменные места вызова.
- Рекурсия поддерживается.
- Рецепт становится известен, когда выполнится его определение, поэтому объявляйте рецепты **до** первого вызова.

```
рецепт факториал(число n) вернёт число
    если n <= 1
        верни 1
    верни n * факториал(n - 1)
```

## Списки

### Объявление

```
список число a = [1, 2, 3]
список(текст) b = ["а", "б"]     ; скобки необязательны
список число пустой              ; пустой список
список список число матрица = [[1, 2], [3, 4]]
```

Все элементы списка должны быть **одного типа**. Тип элементов запоминается по первому добавленному элементу или по объявлению.

### Доступ и изменение

```
покажи(a[0])        ; нумерация с 0
a[1] = 20
a.добавить(4)
a.удалить(0)        ; удалить по номеру
покажи(a.длина())
```

Номер должен быть целым и в пределах списка, иначе — ошибка.

### Команды списка

| Команда | Описание |
|---|---|
| `длина()` | число элементов |
| `добавить(x)` | добавить в конец |
| `удалить(номер)` | удалить элемент по номеру |
| `пусто()` | `верно`, если список пуст |
| `содержит(x)` | есть ли такой элемент (учитывается тип и значение) |

> ⚠️ **Списки, словари и объекты — ссылочные.** `список число b = a` не копирует данные: `a` и `b` указывают на один и тот же список. Это же верно при передаче в рецепты.

## Словари

```
словарь(текст, число) возраст = {"Аня": 10, "Боря": 12}

покажи(возраст["Аня"])
возраст["Вера"] = 11
возраст["Аня"] = 11            ; перезапись

словарь(текст, число) пустой   ; пустой словарь
```

- Ключ — только `число` или `текст`.
- Все ключи одного типа и все значения одного типа.
- Обращение к несуществующему ключу — ошибка; проверяйте заранее через `содержит`.
- Порядок элементов — порядок добавления.

### Команды словаря

| Команда | Описание |
|---|---|
| `длина()` | число пар |
| `пусто()` | пуст ли словарь |
| `содержит(ключ)` | есть ли ключ |
| `получить(ключ, запасное)` | значение или запасное, если ключа нет |
| `удалить(ключ)` | удалить пару (ошибка, если ключа нет) |
| `ключи()` | список ключей |
| `значения()` | список значений |

```
покажи(возраст.получить("Гена", 0))
для текст имя из возраст.ключи()
    покажи(имя + ": " + возраст[имя])
```

## Классы

```
класс Собака
    текст имя = "Без имени"
    число возраст

    рецепт создать(текст имя, число возраст)
        это.имя = имя
        это.возраст = возраст

    рецепт представиться()
        покажи("Я " + это.имя + ", мне " + это.возраст)

    рецепт повзрослеть()
        это.возраст += 1

Собака рекс = Собака("Рекс", 3)
рекс.представиться()
рекс.повзрослеть()
покажи(рекс.возраст)
рекс.имя = "Рексик"
```

- **Поля** объявляются в теле класса: `тип имя` или `тип имя = значение`. Без значения берётся значение типа по умолчанию.
- **`создать`** — конструктор. Если его нет, класс создаётся без аргументов.
- **`это`** — текущий объект внутри рецептов класса.
- Поля читаются и меняются через точку: `объект.поле`, поддерживаются и `+=`, `-=` и т. д.
- Новое поле «на лету» добавить нельзя — только объявленные в классе.
- Тип поля проверяется при присваивании.
- Класс можно использовать как тип: `Собака друг`, `список Собака`, параметры рецептов. Переменную типа класса нужно сразу инициализировать.
- Класс должен быть объявлен **раньше**, чем используется как тип.
- У рецептов класса параметры по умолчанию не поддерживаются: число аргументов должно совпадать точно.
- Объекты — ссылочные (как списки).
- У объекта можно вызывать и общие команды: `в_текст()`, `тип()`.

## Команды (методы) встроенных типов

Вызываются через точку: `значение.команда(аргументы)`. Работают и на литералах: `"abc".длина()`, `16.корень()`.

### Для любого типа

| Команда | Результат |
|---|---|
| `в_текст()` | текстовое представление |
| `тип()` | название типа: `"число"`, `"список число"`, … |

### Текст

Индексы символов считаются с 0 и учитывают UTF-8 (один символ = одна буква, а не байт).

| Команда | Описание |
|---|---|
| `длина()` | число символов |
| `содержит(часть)` | есть ли подстрока |
| `заменить(что, чем)` | заменить все вхождения |
| `пусто()` | пустая ли строка |
| `в_верхний()` / `в_нижний()` | регистр (латиница и кириллица) |
| `обрезать()` | убрать пробелы по краям |
| `начинается_с(п)` / `заканчивается_на(п)` | проверка начала/конца |
| `повторить(n)` | повторить n раз |
| `перевернуть()` | развернуть строку |
| `символ(i)` | символ с номером i |
| `подтекст(начало, длина)` | часть строки |
| `найти(часть)` | номер символа первого вхождения или `-1` |
| `в_число()` | преобразовать в число |

### Число

| Команда | Описание |
|---|---|
| `модуль()` | абсолютное значение |
| `округлить()` | округление до целого |
| `корень()` | квадратный корень (≥ 0) |
| `степень(p)` | возведение в степень |
| `знак()` | `-1`, `0` или `1` |
| `целое()` | целое ли число |
| `чётное()` / `нечётное()` | чётность |
| `минимум(y)` / `максимум(y)` | меньшее/большее из двух |
| `ограничить(мин, макс)` | зажать в диапазон |
| `синус()` / `косинус()` | тригонометрия (радианы) |
| `логарифм()` | натуральный логарифм (> 0) |

Команды списков и словарей описаны в своих разделах.

## Библиотеки

Подключение:

```
используй математика
```

Функции и константы библиотеки становятся доступны глобально. Если библиотеки с таким именем нет, интерпретатор перечислит известные.

### `математика`

**Константы** (тип `число`):

| Имя | Значение |
|---|---|
| `пи` | π |
| `число_эйлера` | e |
| `золотое_сечение` | φ |
| `корень_из_2` | √2 |
| `корень_из_3` | √3 |
| `минус_ноль` | −0 |

**Функции:**

| Функция | Описание |
|---|---|
| `синус(x)`, `косинус(x)`, `тангенс(x)` | тригонометрия (радианы) |
| `степень(x, y)` | x в степени y |
| `корень(x)` | квадратный корень |
| `экспонента(x)` | eˣ |
| `логарифм(x)`, `логарифм10(x)`, `логарифм2(x)` | логарифмы |
| `гиперболический_синус(x)`, `…_косинус(x)`, `…_тангенс(x)` | гиперболические функции |
| `модуль(x)` | абсолютное значение |
| `округление(x)`, `округление_вверх(x)`, `округление_вниз(x)` | округления |
| `гипотенуза(x, y)` | √(x² + y²) |
| `остаток(x, y)` | остаток от деления |
| `минимум(x, y)`, `максимум(x, y)` | меньшее / большее |
| `знак(x)` | −1, 0 или 1 |
| `радианы_в_градусы(x)`, `градусы_в_радианы(x)` | перевод углов |

```
используй математика
покажи(гипотенуза(3, 4))     ; 5
покажи(пи)
```

## Ошибки

Ошибки выводятся в `stderr` в рамке, а программа завершается с кодом `1`. Ошибки разбора содержат номер строки («В строке N: …»). Примеры:

| Ситуация | Сообщение (суть) |
|---|---|
| Забыли отступ после `если` | после этой строки нужен отступ |
| Неверный тип | В переменной «x» должно лежать «число», а ты кладёшь «текст» |
| Нет переменной | Я не знаю переменную «x». Сначала создай её |
| Деление на ноль | Делить на ноль нельзя! |
| Индекс за границами | В списке всего 3 элемента, а ты просишь номер 5 |
| `стоп` вне цикла | «стоп» можно писать только внутри цикла! |
| `верни` вне рецепта | «верни» можно писать только внутри рецепта! |

## Устройство интерпретатора

```
исходный код (.kl)
      │
      ▼
   Lexer      Parser/Lexer.*       UTF-8 → токены (+ INDENT/DEDENT)
      │
      ▼
   Parser     Parser/Parser.*      рекурсивный спуск → AST
      │
      ▼
   AST        Parser/AST/*.h       Statement::execute / Expression::eval
      │
      ▼
 Environment  libs/Environment.h   цепочка областей видимости
```

| Каталог / файл | Назначение |
|---|---|
| `main.cpp` | точка входа, запуск, красивый вывод ошибок |
| `Parser/Lexer.*`, `Token.*`, `TokenType.h` | лексический анализ |
| `Parser/Parser.*` | синтаксический анализ |
| `Parser/AST/` | узлы дерева: выражения (`Expression`) и команды (`Statement`) |
| `libs/Value.h` и `*Value.h` | значения: `NumberValue`, `StringValue`, `BoolValue`, `NothingValue`, `ListValue`, `DictValue`, `ObjectValue` |
| `libs/Environment.h` | переменные и области видимости |
| `libs/Function.h`, `Functions.h` | пользовательские и встроенные рецепты |
| `libs/Classes.h` | таблица классов, создание объектов, вызов методов |
| `libs/Methods.h` | встроенные команды типов |
| `libs/NativeLibs.h`, `KlLibs.h`, `libs/kl/*` | нативные библиотеки |
| `libs/Console.h` | цветной вывод (учитывает `NO_COLOR`, TTY, Windows VT) |

Управляющие конструкции `стоп`, `продолжи` и `верни` реализованы через C++-исключения (`BreakStatement`, `ContinueStatement`, `ReturnException`).

## Как добавить свою библиотеку

1. Создайте файл `libs/kl/<имя>` — обычный C++ с функциями и макросами регистрации:

   ```cpp
   double удвоить(const double x) { return x * 2; }
   KL_EXPORT(удвоить)

   const double ответ = 42;
   KL_CONST(ответ)
   ```

2. Подключите его в `libs/KlLibs.h`, задав имя библиотеки, которое увидит пользователь:

   ```cpp
   #define KL_LIB "мояБиблиотека"
   #include "kl/my"
   #undef KL_LIB
   ```

3. В программе: `используй мояБиблиотека`.

Поддерживаемые типы аргументов и результатов: `bool` (`условие`), `std::string` (`текст`) и любые арифметические типы (`число`; для целочисленных типов проверяется, что число целое). Функции с `void` возвращают `ничего`. Константы регистрируются через `KL_CONST`.

## Известные особенности

Это не ошибки документации, а текущее поведение интерпретатора, о котором полезно знать:

- Список, словарь и объект — **ссылки**: присваивание не копирует данные.
- Рецепты не видят локальных переменных вызывающего кода, только глобальные.
- Рецепты и классы регистрируются при выполнении определения; вызывать их нужно после него. Класс как тип должен быть объявлен выше по тексту.
- Названия классов, списков и словарей в сообщениях об ошибках могут включать тип элементов (`список число`, `словарь текст число`).
- Для `для … от … до …` шаг задаётся только числовым литералом.
- Первая версия: `VERSION 0.1`.
